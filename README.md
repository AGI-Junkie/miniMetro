# Mini Metro 网页复刻

双击 `Mini Metro.html` 可离线玩。开发入口为 `index.html`、`style.css` 和 `metro.js`。项目无外部运行依赖。

## 操作

- 在横向地图页选伦敦、巴黎或纽约，用右下角切换普通、无尽、极限和创意模式。极限模式按城市显示解锁条件，达成后可玩永久轨道规则。也可选择「伦敦入门教程」，按提示连站、插站和过河，再带着同一路网进入第二周。
- 一次按住并经过多个车站可连续连站。拖动端点或线路末端的横杆可延长或缩短，连到另一端可闭环。几秒没有操作时，会用胶囊提示下一步该拖哪里。拖动已有线段到新站可插站，普通和无尽模式中出现在轨道上的新站也可自动接入，把环线的线段拖离可打开环线。
- 底部色点选择线路。可以把机车放到指定轨段，或把车厢拖到附近列车所在的轨道。也可以点图标给所选线路分配。普通和无尽模式可从地图上拖动已投放的机车或车厢，原车到下一站下客后执行调拨。换乘站升级可拖到车站，或先点图标再点车站。
- 乘客图形表示目的站类型。同向列车会保持车距。列车在急弯站停车，平缓路段可通过无需上下客的车站。乘客根据预计到达时间选车，考虑车的位置、行驶方向、候车和换乘。暂停时车头显示方向。过河段消耗通道，线路关闭后，行驶中的列车会驶到下一站再下客并回收资源。选中线路或拖线时，沿线车站会显示线路色圆环。
- 右上角时钟有暂停、正常、双倍三档。按 1、2、3 直接选档，左右键逐档切换。按 Esc 打开暂停菜单，可切换夜间模式和色觉辅助。从暂停菜单进入「城市选择」会保存最后离开的一局，可在同一浏览器重新打开页面后选择「继续运营」。每周领取机车并从两个图标奖励中选一项。选中的奖励会飞入底部工具栏。无尽模式按过去七个游戏日的日均送达量发放里程碑资源。普通模式超载结算后可保留路网继续无尽模式，也可从右下角打开本局统计图、路网回放或照片模式。路网回放可播放、暂停、拖动进度并保存为循环 GIF。照片模式也可从暂停菜单进入，支持带或不带城市标题边框的 PNG 导出。

- 创意模式下可点「编辑车站」新增、改形、调整客流或删除。线路全部解锁，车辆和资源可重复投放。

## 对照范围

- [Steam 官方商店截图](https://store.steampowered.com/app/287980/Mini_Metro/)用来对照城市选择、右上角计分与时钟、底部资源图标、重叠线路、线路端点、虚线过水段和结算版式。研究用截图在 `research/steam-reference`，未打包进游戏。
- [Dinosaur Polo Club 官方地图指南](https://steamcommunity.com/sharedfiles/filedetails/?id=2295902845)用于核对三条起始线路、三种起始站、站点容量 6 / 18、列车及每节车厢容量 6、机车加减速、随机周升级、线路容量上限和地图缩放的设计。
- [原版逆向记录](research/original-reverse-engineering.md)记录了官方旧试玩版的档案获取和 REA 分析覆盖。Windows 正式版文件未取得，旧站归档仅恢复页面和加载器。另已从公开的 Coolmath 伦敦试玩取得 Unity WebGL 2.51.0 构建并分析其 IL2CPP 元数据。[第三方静态分析摘要](research/rea-summary.json)只用于区分先前的实现参考，未当作原版证据。
- 三城昼夜配色来自公开伦敦试玩构建的 Tube、Metro、Subway 配置。日长 20 秒、超载 45 秒及宽限、机车速度与加减速、停站时间、线宽、终端、乘客排布和选址间距来自同一构建的 `Constants` 常量，换算见研究记录。伦敦的河道、候选站点格点和镜头缩放取自同一构建的地图数据，巴黎和纽约的地图轮廓仍是近似。车站出现间隔（28 秒）、开局乘客节奏、3 个起始过河通道、提示和错误横幅的样式、结算文案与周升级的两步流程，来自对原版伦敦试玩构建的实测，做法和限制见研究记录。巴黎普通站容量为 4，较快的出站节奏和较密的选址按开发者公告调整，具体间隔和距离为估计。巴黎、纽约的地图生成配置及无尽、极限、创意模式的完整规则仍缺少可对照数据。动画时序、过河判定、换乘安全余量和客流生成速率仍是近似。车次预测未模拟未来满载或原版的调度细节。已实现行驶中撤线后的末班车。旧轨的显示时长、重新接入条件和调度仍是近似。完整城市、音乐和线上功能仍未覆盖。

## 验证

在 Chrome 用 Playwright CLI 验证多站拖线、闭环及拆环、并行轨迹、撤线末班车与通道占用、按预计时间选车、换乘窗口、结算统计、周升级动画、减弱动态效果、时钟档位、三城昼夜配色及色觉辅助、教程转入普通运营、极限解锁与无尽效率奖励、拖车厢、车辆调拨、同向车距、换乘站容量、结算续玩和切换城市。运行本地入口测试的命令如下。

```powershell
python -m http.server 8767 --bind 127.0.0.1
```

```powershell
npx --package @playwright/cli playwright-cli -s=minimetro open http://127.0.0.1:8767/ --browser=chrome
npx --package @playwright/cli playwright-cli -s=minimetro run-code --filename research/browser-check.js
```
